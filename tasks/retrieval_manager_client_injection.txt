# Task: Add ChromaDB Client Injection to RetrievalManager

## Overview
Add the ability to pass a ChromaDB HTTP client as a parameter to RetrievalManager, enabling better testing with in-memory ChromaDB and improved flexibility for different deployment scenarios.

## Current State
- RetrievalManager currently creates its own ChromaDB HttpClient internally
- Tests fail when trying to use real ChromaDB because they attempt to connect to external server
- No way to inject custom ChromaDB client for testing or different environments

## Goals
1. Enable dependency injection of ChromaDB client
2. Support both external ChromaDB server and in-memory ChromaDB
3. Maintain backward compatibility with existing code
4. Enable proper unit testing with real ChromaDB instances
5. Improve testability and flexibility

```python
def _initialize_vector_store(self):
    """Initialize the ChromaDB vector store with optional client injection."""
    if self.chroma_client is not None:
        # Use injected client (for testing or custom scenarios)
        self.chroma_client = self.chroma_client
    else:
        # Create default HttpClient for external server
        self.chroma_client = chromadb.HttpClient(
            host=self.chroma_host,
            port=self.chroma_port,
            settings=self.chroma_settings or ChromaSettings(
                allow_reset=True,
                anonymized_telemetry=False
            )
        )
```

```python
def get_in_memory_retrieval_manager() -> RetrievalManager:
    """Get RetrievalManager with in-memory ChromaDB for testing."""
    import chromadb
    client = chromadb.Client()
    return RetrievalManager(chroma_client=client)
```

### Client Type Detection
```python
def _detect_client_type(self, client: chromadb.ClientAPI) -> str:
    """Detect if client is HttpClient or in-memory Client."""
    if hasattr(client, 'get_tenant'):
        return "http"  # HttpClient
    else:
        return "memory"  # In-memory Client
```
