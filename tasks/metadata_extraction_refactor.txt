# Metadata Extraction Refactoring and Month Addition

## Overview
This task involves refactoring the metadata extraction functionality in the Disney reviews pipeline to:
1. Add month as a separate metadata field extracted from the Year_Month column
2. Refactor data extraction into separate, testable functions
3. Improve code organization and maintainability
4. Add comprehensive tests for each extraction function

## Current State Analysis

### Current Data Structure
- **Year_Month Column Format**: `YYYY-M` (e.g., "2019-4", "2020-12")
- **Current Extraction**: Only year is extracted, month is ignored
- **Location**: `src/disney/pipeline/ingest.py` - `preprocess_reviews()` method

### Current Issues
1. **Monolithic extraction**: All metadata extraction happens in one method
2. **No month extraction**: Month information is lost
3. **Hard to test**: Extraction logic is embedded in the main pipeline
4. **No validation**: No validation of extracted metadata
5. **Code duplication**: Similar extraction logic exists in DocumentProcessor

## Goals
1. **Add month metadata**: Extract month from Year_Month column
2. **Refactor extraction**: Create separate functions for each metadata field
3. **Improve testability**: Make each extraction function independently testable
4. **Add validation**: Validate extracted metadata values
5. **Consolidate logic**: Unify extraction logic between pipeline and DocumentProcessor
6. **Maintain backward compatibility**: Ensure existing functionality continues to work

**Updated preprocess_reviews() method**:
```python
def preprocess_reviews(self, df: pd.DataFrame) -> List[Dict[str, Any]]:
    """Preprocess reviews data for indexing with improved metadata extraction."""
    try:
        documents = []
        extractor = MetadataExtractor()
        
        with tqdm(total=len(df), desc="Preprocessing reviews", unit="review") as pbar:
            for idx, row in df.iterrows():
                # Extract review text
                review_text = str(row.get('Review_Text', '')).strip()
                if not review_text or review_text == 'nan':
                    pbar.update(1)
                    continue
                
                # Extract metadata using individual functions
                rating = extractor.extract_rating(row.get('Rating'))
                year = extractor.extract_year(str(row.get('Year_Month', '')))
                month = extractor.extract_month(str(row.get('Year_Month', '')))
                branch = extractor.extract_branch(row.get('Branch'))
                review_id = extractor.extract_review_id(row.get('Review_ID', idx))
                location = extractor.extract_reviewer_location(row.get('Reviewer_Location'))
                
                # Create document with comprehensive metadata
                doc = {
                    'id': review_id,
                    'content': review_text,
                    'metadata': {
                        'rating': rating,
                        'year': year,
                        'month': month,  # NEW: Month metadata
                        'branch': branch,
                        'reviewer_location': location,  # NEW: Reviewer location
                        'original_index': idx
                    }
                }
                
                documents.append(doc)
                pbar.update(1)
        
        logger.info(f"Preprocessed {len(documents)} review documents")
        return documents
        
    except Exception as e:
        logger.error(f"Error preprocessing reviews: {str(e)}")
        raise
```

### Validation Functions
```python
def validate_month(self, month: int) -> bool:
    """Validate month is between 1-12."""
    return 1 <= month <= 12

def validate_year(self, year: int) -> bool:
    """Validate year is reasonable (2000-current)."""
    current_year = datetime.now().year
    return 2000 <= year <= current_year
```
