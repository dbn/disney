# Task: Implement Query Parser Component for Metadata Extraction

## Overview
Implement a query parser component that uses LLM to extract metadata from user queries and convert them into structured filters for ChromaDB retrieval. This will enhance the existing RAG system by allowing users to query with natural language that includes specific metadata constraints.

## Current State
- Existing RAG system with RetrievalManager
- Document ingestion with metadata: `rating`, `year`, `branch`, `original_index`
- ChromaDB integration with collection-based isolation
- LangChain-based query processing

## Goals
1. Extract metadata from natural language queries using LLM
2. Convert extracted metadata to ChromaDB where clause filters
3. Rewrite queries for better semantic search
4. Integrate seamlessly with existing RetrievalManager
5. Handle edge cases gracefully
6. Reuse existing LangChain infrastructure

### Phase 3: Implement Core Query Parser
**File:** `src/disney/rag/query_parser.py`

**Key Methods:**
```python
class QueryParser:
    def __init__(self, config: QueryParserConfig):
        self.config = config
        self.llm = ChatOpenAI(
            model=config.llm_model,
            temperature=config.temperature,
            max_tokens=config.max_tokens
        )
        self.prompt_template = ChatPromptTemplate.from_template(METADATA_EXTRACTION_PROMPT)
        self.chain = self.prompt_template | self.llm | StrOutputParser()
    
    async def parse_query(self, query: str) -> QueryParseResult:
        """Parse user query and extract metadata."""
        
    def _validate_extracted_metadata(self, metadata: Dict[str, Any]) -> Tuple[Dict[str, Any], List[str]]:
        """Validate and clean extracted metadata."""
        
    def _build_chromadb_filters(self, metadata: Dict[str, Any]) -> Dict[str, Any]:
        """Convert metadata to ChromaDB where clause format."""
        
    def _handle_parsing_errors(self, result: Dict[str, Any]) -> QueryParseResult:
        """Handle cases where LLM parsing fails."""
```

    async def query_with_metadata(self, query: str) -> str:
        """Enhanced query method with metadata extraction."""
        # Parse query for metadata
        parse_result = await self.query_parser.parse_query(query)
        
        # Use metadata filters if available

                parse_result.search_query,

### Phase 5: Edge Case Handling
**File:** `src/disney/rag/query_parser.py`

**Edge Cases:**
1. **No metadata extracted**: Return empty filters, use original query
2. **Invalid metadata format**: Fallback to original query, log warning
3. **LLM parsing failure**: Use original query, return error details
4. **Confidence too low**: Use original query, log warning
5. **Empty query**: Return error result
6. **Malformed JSON**: Retry with simplified prompt

**Implementation:**
```python
async def parse_query(self, query: str) -> QueryParseResult:
    """Parse user query with comprehensive error handling."""
    if not query or not query.strip():
        return QueryParseResult(
            original_query=query,
            search_query="",
            filters={},
            confidence=0.0,
            extracted_metadata={},
            parsing_errors=["Empty query provided"]
        )
    
    try:
        # Attempt LLM parsing
        result_json = await self.chain.ainvoke({"query": query.strip()})
        result = json.loads(result_json)
        
        # Validate and clean metadata
        clean_metadata, errors = self._validate_extracted_metadata(
            result.get("filters", {})
        )
        
        # Build ChromaDB filters
        chromadb_filters = self._build_chromadb_filters(clean_metadata)
        
        return QueryParseResult(
            original_query=query,
            search_query=result.get("search_query", query),
            filters=chromadb_filters,
            confidence=result.get("confidence", 0.0),
            extracted_metadata=clean_metadata,
            parsing_errors=errors
        )
        
    except json.JSONDecodeError:
        return self._handle_json_parsing_error(query, result_json)
    except Exception as e:
        return self._handle_general_error(query, str(e))
```
